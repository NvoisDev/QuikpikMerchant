🧾 Prompt: Add Pack Size Format (e.g. “10 × 2kg”) – NON-BREAKING
🎯 Objective

Display product pack size in the format:

"10 × 2kg"
"24 × 250mL"

across:

Product information card
Product detail (full view) page
Invoices
Quotes

This is display-only metadata and must NOT affect any calculations or existing logic.

🚨 NON-NEGOTIABLE RULES
1. NO impact on logic
Do NOT modify:
Pricing calculations
Stock calculations
Order quantities
Batch logic

👉 This is informational only

2. NO breaking schema changes
Do NOT rename or remove existing fields
Only add optional fields if required
3. NO behavioural changes
Orders, invoices, and quotes must behave exactly the same
This must not affect totals, weights, or units used in logic
🧠 Data Structure (SAFE APPROACH)
Option A (Preferred – structured)

Add optional fields to products:

pack_quantity   (e.g. 10)
pack_unit_size  (e.g. 2)
pack_unit_type  (e.g. "kg", "g", "mL", "L")
Option B (Fallback – simple)
pack_display = "10 × 2kg"

👉 Use only if structured fields are not feasible

🧮 Display Logic

If structured fields exist:

pack_display = pack_quantity + " × " + pack_unit_size + pack_unit_type

Example:

10 × 2kg
24 × 250mL

1. Product Card (List View)
Show under product name or near unit type
Smaller font / muted colour

Example:

Heineken Beer

Include in Product Info section
