🔥 First — your core question (important)

If no phone number is included, what should happen?

Here’s the clean, scalable answer:

✅ Recommended behaviour

Allow invoice creation with just a name (no phone)
BUT treat it as a “light / unlinked customer”

Scenario	Behaviour
Name only	Create invoice + allow sharing manually
Name + phone	Create full customer + portal access
Later phone added	Link past orders automatically
🧠 Why this is the right move
Removes friction → faster invoice creation
Matches real-world behaviour (not every order starts with full details)
Keeps your system clean (you’re not forcing fake data)
Lets you upgrade the customer later
💡 Clean mental model

Think of 2 states:

Draft Customer (Name only)
No login
No portal access
Just used for invoicing + tracking
Active Customer (Phone added)
Can log in (SMS OTP)
Gets order history
Receives payment links properly
