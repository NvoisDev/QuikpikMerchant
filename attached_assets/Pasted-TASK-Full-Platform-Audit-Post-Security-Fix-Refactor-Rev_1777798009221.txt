TASK: Full Platform Audit — Post-Security Fix & Refactor Review

Context:
We have just completed:
- Removal of sensitive debug logs
- Secure cookie fix (secure: true in production)
- Rate limiting on auth + OTP endpoints
- NaN guards added to route params
- Limit cap added to marketplace queries

The platform is currently stable and all tests are passing.

Your job is to perform a COMPLETE audit of the codebase to identify:
1. Any regressions introduced
2. Remaining risks (security, data, performance)
3. Structural weaknesses that will become problems at scale
4. Opportunities to simplify or reduce complexity WITHOUT breaking behaviour

---

SECTION 1 — Regression & Stability Check

- Verify no functionality was broken by recent changes
- Check:
  - Auth flows (wholesaler + customer)
  - OTP login
  - Checkout (Stripe + Pay Later)
  - Order creation + fulfilment
  - Customer creation + portal access
- Confirm:
  - No new 500 errors possible from added guards
  - Rate limiting does not block legitimate users

Output:
- List of any regressions or edge cases introduced

---

SECTION 2 — Security Audit (Deep)

Re-check entire backend for:

- Any remaining:
  - console.log dumping sensitive data
  - unsecured endpoints
  - missing auth guards

  - All admin routes require auth
  - Tenant isolation is enforced everywhere (no cross-wholesaler access)
- Review:
  - Session handling
  - Cookie settings
  - OTP flows (brute-force protection)

Output:
- Any remaining vulnerabilities ranked by severity

SECTION 3 — API & Backend Risk

- Identify:
  - Routes >2000 lines (high complexity risk)
  - Any route doing too many responsibilities
- Check for:
  - Duplicate logic across routes (orders, payments, marketplace)
  - Inconsistent validation patterns
  - Missing input validation beyond NaN

Output:
- Top 5 backend risks
- Suggested split points (NOT implementation, just identification)

---

SECTION 4 — Frontend Complexity & Maintainability

- Identify:

- Top 5 frontend refactor candidates

- Any inconsistencies or silent failure risks
