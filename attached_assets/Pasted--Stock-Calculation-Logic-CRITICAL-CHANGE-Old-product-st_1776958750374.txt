🔄 Stock Calculation Logic (CRITICAL CHANGE)
Old:
product.stock = manual value
New:
product.total_stock = SUM(all active batch quantities)

👉 Product stock becomes derived, not stored manually

📦 Stock In (Purchases / Restocking)

When new stock is added:

ALWAYS create a new batch record

Example:

+100 units of Coca-Cola
Expiry: 01-Jan-2027
→ Create new batch

👉 Do NOT merge with existing batches (even if same product)

📤 Stock Out (Orders / Sales)
Implement FEFO (First Expiry First Out)
Sort batches by expiry_date ASC
Reduce stock from earliest expiry first
Example:
Batch	Qty	Expiry
A	50	Jan
B	100	March

Order = 60 units:

Take 50 from Batch A
Take 10 from Batch B
⚠️ Expiry Handling
Add logic:
Automatically mark batch as:
status = expired

when:

expiry_date < today
Expired stock:
Excluded from available stock
Still stored for reporting

⚠️ Backward Compatibility (VERY IMPORTANT)

For existing products:

Convert current stock into a default batch
batch_name: "Initial Stock"
expiry_date: NULL (or far future)
quantity: existing stock

👉 Prevents breaking current data

🔐 Edge Cases to Handle
Products without expiry → allow NULL expiry
Same expiry, multiple deliveries → separate batches
Partial batch depletion → keep batch until quantity = 0
Returns → optionally reassign to original batch
