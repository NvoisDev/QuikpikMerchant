🧾 Prompt: Quote Activity Log (Mobile-Optimised, Modern UI, NON-BREAKING)
🎯 Objective

Add a Quote Activity / History log to Quick Quotes that tracks all key actions (edits, payments, status changes) with a clean, modern, mobile-first UI, without affecting existing logic or performance.

🚨 NON-NEGOTIABLE RULES
Do NOT modify existing order/quote logic
Do NOT interfere with stock, payments, or Stripe
Do NOT slow down quote loading
Do NOT store logs as plain text only
Do NOT break mobile layout

👉 This is an additive feature only

🧱 PART 1 — DATA STRUCTURE (SAFE & SCALABLE)

Create a new table:

quote_activity_logs
Fields:
id (uuid)
quote_id (fk)
action_type (string) 
entity_type (string)  // product, payment, quote, system
entity_id (nullable)
old_value (jsonb)
new_value (jsonb)
description (string) // fallback display
performed_by (user_id or 'system')
created_at (timestamp)
✅ Rule:
Use structured data (json) for flexibility
description is just for quick UI rendering
🧱 PART 2 — TRACKED EVENTS

Log ONLY key actions:

🧾 Creation
Quote created
✏️ Edits
Product added
Product removed
Quantity changed
Price changed (if applicable)
Delivery cost changed
Total updated
💳 Payments
Payment initiated
Payment successful
Payment failed
❌ Status
Quote cancelled
Quote expired (future-proof)
⚙️ System
Stock restored
Auto updates
🧱 PART 3 — BACKEND LOGGING (NON-INTRUSIVE)

At key points in existing logic:

👉 ADD logging
👉 DO NOT modify logic

Example:
await createQuoteActivityLog({
  quoteId,
  actionType: 'quantity_changed',
  entityType: 'product',
  entityId: productId,
  oldValue: { quantity: 10 },
  newValue: { quantity: 6 },
  performedBy: req.user.id
});
⚠️ Rule:

If logging fails:

DO NOT break the main flow

Logging must be non-blocking

🧱 PART 4 — API ENDPOINT

Create:

GET /api/quotes/:id/activity
Requirements:
Sorted by created_at DESC
Paginated (default 20)
Lightweight response
