🧾 Prompt: Upgrade Admin Panel → Platform Control Centre (NON-BREAKING)
🎯 Objective

Redesign the existing admin page into a modern, structured control centre that allows the platform owner to:

Monitor platform health
Support wholesalers quickly
Take action (fix issues, override, assist users)
Navigate easily without clutter

All changes must be non-breaking and additive.

🧠 Core Principle

Admin ≠ Settings page
Admin = Operations + Support + Control

Overview
Wholesalers
Customers
Orders

Failed payments

Disable account
