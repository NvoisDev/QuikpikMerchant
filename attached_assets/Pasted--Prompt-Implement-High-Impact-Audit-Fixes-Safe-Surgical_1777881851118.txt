🟠 TASK 2 — Centralise Wholesaler Resolution
Problem

This logic is duplicated 30+ times:

const targetUserId =
  req.user.role === 'team_member' && req.user.wholesalerId
    ? req.user.wholesalerId
    : req.user.id;
Implementation

Create:

server/utils/resolveWholesalerId.ts
export function resolveWholesalerId(req: Request): number {
  if (!req.user) throw new Error('User missing from request');

  if (req.user.role === 'team_member' && req.user.wholesalerId) {
    return req.user.wholesalerId;
  }

  return req.user.id;
}
Then:
Replace ALL inline occurrences across route files
Rules
No behaviour change
Must work for all roles

export function calculateOrderPricing({
  subtotal,
  feeConfig,
}: {
  subtotal: number;
  feeConfig: FeeConfig;
}) {
  const customerFee = calculateCustomerFee(subtotal, feeConfig);
  const platformFee = subtotal * feeConfig.percentage;

  return {
    customerFee,
    platformFee,
    total: subtotal + customerFee,
    feeSnapshot: {
      percentage: feeConfig.percentage,
      fixed: feeConfig.fixed,
    },
  };
}
